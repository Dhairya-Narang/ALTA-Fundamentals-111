# 🚀 ALTA Fundamentals 111 --- DSA Journey

Welcome to my **ALTA Fundamentals 111 --- DSA Sheet (Pre-APEX)**
journey.

This repository contains my solutions to **111 programming problems**,
with the goal of solving **one problem every day for 111 consecutive
days** and building strong programming and DSA fundamentals step by
step.

## 🎯 Challenge Goal

-   Solve **1 problem every day**
-   Complete **111 problems**
-   Build strong programming fundamentals
-   Progress from basic programming concepts towards DSA
-   Prepare for **ALTA APEX 151**

## 🧠 Topics Covered

The sheet progresses through:

-   Programming Basics
-   Variables
-   Operators
-   If-Else
-   Switch Case
-   Loops
-   Functions
-   Arrays
-   Strings
-   Structures / Classes
-   Recursion
-   Searching
-   Sorting
-   Linked Lists
-   Stacks & Queues
-   Trees
-   Graphs
-   Other DSA fundamentals

## 💻 Language

**C**
